## 加密（Cryptography）

| 工具 | slug | 一句话用途 |
| --- | --- | --- |
| 数字签名 | `signature` | 用私钥签名、用公钥验签 |
| 非对称加解密 | `asymmetric-crypt` | RSA / SM2 加解密 |
| 对称加解密 | `symmetric-crypt` | SM4 / AES 加解密 |
| ECDH 密钥协商 | `ecdh` | 双方协商出共享密钥 |
| SM4 文件加解密 | `sm4-file-crypt` | 整文件分块加密 |
| HMAC 计算 | `hmac-gen` | 计算消息认证码 |

| 摘要计算 | `hash-calc` | 计算 MD5 / SHA / SM3 摘要 |

### 数字签名（Digital Signature）

- **用途**：用私钥对消息签名，用公钥验证签名是否有效。
- **输入**：算法（SM2 / RSA / ECDSA / Ed25519 / Ed448）、操作（签名 / 验签）、消息、私钥或公钥、签名。
- **输出**：签名（默认 DER 编码）或验签结论 `valid`。
- **默认**：SM2 userId `1234567812345678`；摘要 `SHA256`（RSA / ECDSA）；RSA 填充 `PSS`。
- **安全提示**：签名与验签使用**不同的 userId** 会导致验签失败；Ed25519 / Ed448 **不**支持自定义摘要。

**常见问题**

- **Q：验签显示 `valid: false` 是出错了吗？** A：不是，这是**业务结论** —— 消息被改动、密钥不配对或 userId 不一致都会导致该结果。
- **Q：SM2 签名能直接给 `openssl` 验吗？** A：可以，输出为 ASN.1 DER，与 OpenSSL 兼容。

### 非对称加解密（Asymmetric Encryption）

- **用途**：用公钥加密、用私钥解密，适合小数据与密钥交换。
- **输入**：算法（RSA / SM2 / ECIES）、操作、密钥、密文或明文。
- **输出**：密文。
- **默认**：SM2 输出 `C1C3C2` + `04` 前缀 + 裸格式；RSA 用 OAEP + SHA-256。
- **安全提示**：RSA 密文**长度受限**，大文件请用 [SM4 文件加解密](#sm4-文件加解密sm4-file-encryption)。

**常见问题**

- **Q：SM2 密文能被 Java 库解开吗？** A：多数实现用 `C1C3C2`，与本工具默认一致；若报格式错误，请切换为 `C1C2C3` 或 `DER`。
- **Q：RSA 报「明文过长」怎么办？** A：RSA 只能加密极少量数据，请改用对称加密。

### 对称加解密（Symmetric Encryption）

- **用途**：用共享密钥加解密文本数据。
- **输入**：算法（SM4 / AES / DES / 3DES）、模式（ECB / CBC / CTR / OFB / CFB / GCM）、填充、密钥、IV、附加数据、认证标签。
- **输出**：密文或明文，以及 GCM 认证标签。
- **默认**：填充 `pkcs7`；输出 `base64`；SM4 / AES 密钥 16 或 32 字节；GCM nonce 12 字节、tag 16 字节。
- **安全提示**：**不要**使用 ECB 模式；非 GCM 模式**没有**完整性校验，推荐 GCM。

**常见问题**

- **Q：GCM 解密报 `TAG_INVALID`？** A：tag 缺失、被截断，或密钥 / nonce / AAD 与加密时不一致。
- **Q：`padding: none` 报长度错误？** A：该模式要求输入是 16 字节的整数倍。

### ECDH 密钥协商（ECDH Key Agreement）

- **用途**：双方各自持有私钥，协商出同一份共享密钥。
- **输入**：曲线（P-256 / P-384 / P-521 / X25519 / X448）、本方私钥、对端公钥、可选 KDF 参数。
- **输出**：共享密钥与派生密钥。
- **默认**：不做 KDF 派生时直接输出原始共享密钥。
- **安全提示**：共享密钥**必须**再经 KDF 派生后使用；**不要**把原始共享密钥直接当会话密钥。

**常见问题**

- **Q：为什么加了解码后双方结果不一致？** A：检查双方曲线是否相同、公钥是否被压缩或转换过。

### SM4 文件加解密（SM4 File Encryption）

- **用途**：对整个文件做分块加密，支持大文件。
- **输入**：操作、模式（GCM）、密钥、可选 nonce、文件。
- **输出**：加密后文件（`.sm4` 容器）或解密后的原文件。
- **默认**：分块 1 MB；未提供 nonce 时随机生成。
- **安全提示**：密钥**不会**被保存，请自行保管；解密需要**完全相同**的密钥。

**常见问题**

- **Q：支持多大文件？** A：单次请求上限 100 MB。
- **Q：加密后的文件能直接用 `openssl` 解吗？** A：不能，本工具使用自定义容器格式。

### HMAC 计算（HMAC Generator）

- **用途**：计算消息认证码，用于接口签名与完整性校验。
- **输入**：算法（SM3 / SHA1 / SHA224 / SHA256 / SHA384 / SHA512 / MD5）、密钥、消息或文件。
- **输出**：HMAC 值。
- **默认**：输出十六进制。
- **安全提示**：HMAC 密钥**不能**与服务端共享；SHA1 / MD5 **不**应用于安全场景。

**常见问题**

- **Q：算出来的值和对方不一致？** A：逐项核对：算法、密钥编码（hex 还是 utf8）、消息编码、大小写。

### 密码生成（Password Generator）

- **用途**：生成高强度随机密码。
- **输入**：长度、数量、字符集、是否排除易混字符、是否要求每类字符至少一个。
- **输出**：密码列表与单密码的估算熵。
- **默认**：长度 16，数量 1，包含大小写 + 数字 + 符号。
- **安全提示**：本工具在**服务端**生成，密码**不**写入日志与统计；请用完后及时清理页面。

**常见问题**

- **Q：熵值多少才够？** A：一般服务 ≥ 60 bit，重要账户 ≥ 80 bit。

### 摘要计算（Hash Calculator）

- **用途**：计算文件的校验和。
- **输入**：算法列表、文本或文件。
- **输出**：各算法摘要与输入字节数。
- **默认**：输出十六进制。
- **安全提示**：摘要**不是**加密，无法还原原文；MD5 / SHA1 **不**应用于安全场景。

**常见问题**

- **Q：怎么校验下载文件完整性？** A：用相同算法分别计算本地文件与下载文件的摘要并比对。

## 密钥（Keys）

| 工具 | slug | 一句话用途 |
| --- | --- | --- |
| 密钥生成 | `keygen` | 生成 RSA / SM2 / EC 等密钥对 |
| 密钥格式转换 | `key-convert` | PKCS#1 / PKCS#8 / SPKI / DER 互转 |
| 密钥解析 | `key-parse` | 查看密钥算法、长度、参数 |
| 密钥运算 | `key-ops` | 私钥加解密、提取公钥、改口令 |
| 密钥配对检测 | `key-match` | 判断私钥与公钥 / 证书是否配对 |
| JWK/XML 转换 | `jwk-xml-convert` | JWK / PEM / XML 互转 |

### 密钥生成（Key Generator）

- **用途**：生成新的非对称密钥对。
- **输入**：算法、位数（RSA）、曲线（EC / SM2）、输出格式、是否用口令加密。
- **输出**：私钥 PEM、公钥 PEM。
- **默认**：RSA 2048 位；私钥 `PKCS#8`；公钥 `SPKI`；**不**加密。
- **安全提示**：私钥**只在响应中出现一次**，请立即保存；请用口令加密后再长期保存。

**常见问题**

- **Q：为什么私钥没口令也能下载？** A：默认不加密便于导入其它工具；长期保存**建议**加密。
- **Q：SM2 用哪种曲线？** A：选 `SM2`（对应 SM2 推荐参数），不是 P-256。

### 密钥格式转换（Key Format Converter）

- **用途**：在不同密钥格式之间转换。
- **输入**：密钥、源格式、目标格式、现有口令。
- **输出**：转换后的 PEM 与识别到的元信息。
- **默认**：源格式 `auto`（PEM → DER → base64 → hex 顺序识别）。
- **安全提示**：转换过程在服务端内存中完成，不落盘。

**常见问题**

- **Q：`PKCS#1` 和 `PKCS#8` 有什么区别？** A：PKCS#1 是 RSA 专有格式；PKCS#8 是通用格式，**推荐**使用。
- **Q：能转成公钥格式吗？** A：私钥 → `SPKI` 不支持，请先提取公钥。

### 密钥解析（Key Parser）

- **用途**：查看密钥的算法、长度、曲线与参数。
- **输入**：密钥、口令。
- **输出**：算法、类型、格式、指纹、RSA 参数、规范化 PEM。
- **默认**：无。
- **安全提示**：解析**私钥**会显示敏感参数，请勿在共享屏幕下使用。

**常见问题**

- **Q：SHA-256 指纹是什么？** A：密钥公钥部分的哈希，可用于比对两把密钥是否相同。

### 密钥运算（Key Operations）

- **用途**：给私钥加解密、从中提取公钥、修改加密口令。
- **输入**：操作、密钥、口令、新口令。
- **输出**：操作后的 PEM。
- **默认**：PBE 算法 `AES-256-CBC`。
- **安全提示**：修改口令**不会**改变密钥本身，只是重新加密存储。

**常见问题**

- **Q：提取公钥需要口令吗？** A：不需要。

### 密钥配对检测（Key Pair Matcher）

- **用途**：判断私钥与公钥（或证书）是否属于同一对。
- **输入**：两段密钥材料。
- **输出**：是否匹配、结论说明、双方指纹。
- **默认**：无。
- **安全提示**：只比对公钥部分，**不**会泄露私钥。

**常见问题**

- **Q：能对比私钥和证书吗？** A：可以，服务端会提取证书的公钥再比对。

### JWK/XML 转换（JWK & XML Converter）

- **用途**：在 JWK（JSON Web Key）、PEM、XML（`ds:KeyInfo`）之间互转。
- **输入**：源格式与内容、目标格式、密钥类型。
- **输出**：转换结果。
- **默认**：私钥导出 JWK **必须**显式指定 `keyType: "private"`。
- **安全提示**：导出私钥的 JWK **包含完整私钥材料**，等同于私钥本身。

**常见问题**

- **Q：JWK 里的 `kty` 是什么？** A：密钥类型，`RSA` 或 `EC`。

### 证书解析（Certificate Parser）

- **用途**：查看证书的颁发者、主体、有效期、扩展、指纹。
- **输入**：证书（PEM / DER / base64 / hex）、可选的判断时刻。
- **输出**：证书详情、有效性状态、剩余天数、指纹、是否自签名。
- **默认**：按当前时间判断有效性。
- **安全提示**：只读工具，不修改任何材料。

**常见问题**

- **Q：怎样确认某张证书是否自签名？** A：`selfSigned` 为 `true`，且颁发者与主体一致。
- **Q：证书还没到生效时间怎么办？** A：会提示「尚未生效」，可传入 `atTime` 指定其它时刻判断。

### CSR 生成（CSR Generator）

- **用途**：生成提交给 CA 的证书签名请求。
- **输入**：主体信息、密钥参数、SAN、用途扩展、挑战口令。
- **输出**：CSR PEM（及新生成的私钥）。
- **默认**：自动生成新密钥；私钥格式 PKCS#8。
- **安全提示**：私钥**必须**自行安全保存 —— 丢失后只能重新生成。

**常见问题**

- **Q：CSR 里的 SAN 会被 CA 采纳吗？** A：多数 CA 会核对，**不要**在 CSR 里写与主体不符的域名。
- **Q：能复用已有私钥吗？** A：可以，传入 `existingPrivateKey`，此时响应**不**返回私钥。

### CSR 解析（CSR Parser）

- **用途**：查看 CSR 的主体、SAN、公钥与扩展。
- **输入**：CSR。
- **输出**：主体、SAN、公钥信息、签名算法、扩展、指纹。
- **默认**：无。
- **安全提示**：只读工具。

**常见问题**

- **Q：CSR 有有效期吗？** A：没有，但部分 CA 会限制重复提交频率。

### PEM/DER 转换（PEM & DER Converter）

- **用途**：在 PEM（文本）与 DER（二进制）之间转换。
- **输入**：内容与格式、目标格式、可选 PEM 标签。
- **输出**：转换结果与识别到的标签列表。
- **默认**：输入格式自动识别。
- **安全提示**：无。

**常见问题**

- **Q：PEM 头部的 `BEGIN` 后面是什么？** A：对象类型标识（`CERTIFICATE`、`PRIVATE KEY`、`PUBLIC KEY`、`CERTIFICATE REQUEST`…）。

### ASN.1 视图（ASN.1 Viewer）

- **用途**：把 DER 字节展开成结构树，便于排查证书问题。
- **输入**：DER / base64 / PEM。
- **输出**：长度、节点树、十六进制转储。
- **默认**：最大深度 32。
- **安全提示**：无。

**常见问题**

- **Q：能看懂扩展里的 OID 吗？** A：可以，常见 OID 附中文说明。

### 证书链解析（Certificate Chain Parser）

- **用途**：把散乱的证书整理成正确顺序的链。
- **输入**：多个证书（拼接即可）。
- **输出**：排序后的链、是否已排序、是否缺根、是否自签名。
- **默认**：无。
- **安全提示**：无。

**常见问题**

- **Q：链应该按什么顺序？** A：叶证书 → 中间 CA → 根 CA。

### 证书链验证（Certificate Chain Verifier）

- **用途**：验证证书链是否可信、是否过期、是否匹配域名。
- **输入**：证书链、可选受信任根、可选验证时刻、可选主机名。
- **输出**：是否可信、错误列表、逐张证书的结论、域名匹配结果。
- **默认**：用系统受信任根。
- **安全提示**：验证失败**不是**错误，返回 `valid: false` 与原因列表。

**常见问题**

- **Q：自签名证书能通过验证吗？** A：若把该证书加入受信任根列表，则可以通过。
- **Q：如何验证内网私有 CA 的证书？** A：把 CA 证书作为 `trustedRoots` 传入。

### 证书链修复（Certificate Chain Repairer）

- **用途**：补全缺失的中间证书。
- **输入**：叶证书、可选受信任根。
- **输出**：补全后的链、补充数量与来源、是否到达根。
- **默认**：无。
- **安全提示**：只做**本地**匹配与排序，**不**联网下载。

**常见问题**

- **Q：能自动从网上下载缺失的中间证书吗？** A：不能，本工具纯本地；请用 [证书链获取](#证书链获取certificate-chain-fetcher) 或手工补充。

### 吊销状态检查（Revocation Checker）

- **用途**：用 CRL 判断证书是否已被吊销。
- **输入**：证书、CRL。
- **输出**：`good` / `revoked` / `unknown`。
- **默认**：无。
- **安全提示**：需要提供 CRL 文件，**不**联网获取。

**常见问题**

- **Q：`unknown` 是什么意思？** A：CRL 中没有该证书的记录 —— 可能是**未吊销**，也可能是 CRL 不完整。

### CRL 解析（CRL Parser）

- **用途**：查看吊销列表中的条目。
- **输入**：CRL。
- **输出**：签发者、有效期、签名算法、被吊销条目列表。
- **默认**：无。
- **安全提示**：无。

**常见问题**

- **Q：吊销原因码怎么看？** A：`reasonCode` 是 RFC 5280 定义的数字，工具同时给出中文说明。

### CRL 生成（CRL Generator）

- **用途**：用 CA 证书与私钥签发吊销列表。
- **输入**：签发者证书与私钥、编号、有效期、吊销条目。
- **输出**：CRL 的 PEM 与 DER。
- **默认**：编号自动生成；有效期由签发者证书推导。
- **安全提示**：CRL 私钥等同 CA 私钥，请妥善保管。

**常见问题**

- **Q：CRL 有效期怎么设？** A：按业务需要设置 `nextUpdate`，过长会导致吊销信息延迟生效。

### OCSP 请求生成（OCSP Request Builder）

- **用途**：生成发给 OCSP 响应方的请求数据。
- **输入**：证书、签发者证书、哈希算法。
- **输出**：DER 编码的请求（base64 与 hex）。
- **默认**：哈希 `SHA1`。
- **安全提示**：无。

**常见问题**

- **Q：哈希能用 SHA-256 吗？** A：可以，但部分 OCSP 服务端只支持 SHA-1。

### OCSP 响应解析（OCSP Response Parser）

- **用途**：查看 OCSP 响应中的证书状态。
- **输入**：OCSP 响应、证书、签发者证书。
- **输出**：响应级状态、证书状态、时间信息、响应者证书。
- **默认**：无。
- **安全提示**：解析**不**等于验证响应者身份，**不**等于验证签名真实性。

**常见问题**

- **Q：为什么状态是 `unknown`？** A：OCSP 响应本身不包含该证书的状态。

### 证书生成（Certificate Generator）

- **用途**：自签证书，或用 CA 证书签发子证书。
- **输入**：签发模式、签发者证书与私钥（或 CSR / 模板）、主体信息、密钥、SAN、用途、有效期。
- **输出**：证书 PEM、私钥 PEM（若新生成）、完整链。
- **默认**：随机序列号；有效期 365 天；签名算法按密钥类型自动选择。
- **安全提示**：**不要**用本工具签发的证书直接用于生产环境 —— 请用正式 CA。

**常见问题**

- **Q：自签名证书和 CA 签发有什么区别？** A：自签名是**自己**签自己，浏览器不信任；CA 签发需要上级 CA 的证书与私钥。
- **Q：怎么延长有效期？** A：调整 `notAfterDays` 或直接指定 `notAfter`。

### PKCS#12 打包（PKCS#12 Packer）

- **用途**：把证书、私钥与链打包成 `.pfx` / `.p12`。
- **输入**：证书、私钥（可选）、链（可选）、口令、别名（可选）。
- **输出**：PKCS#12 内容（base64）。
- **默认**：别名 `toolbit`。
- **安全提示**：PKCS#12 **必须**设口令；空口令的 `.pfx` 极不安全。

**常见问题**

- **Q：`.pfx` 和 `.p12` 是同一个东西吗？** A：是，PKCS#12 的两种常见扩展名。

### PKCS#12 解析（PKCS#12 Parser）

- **用途**：读取 `.pfx` 中的证书、链与私钥。
- **输入**：PKCS#12 内容（base64）、口令。
- **输出**：主证书、附加证书、私钥。
- **默认**：无。
- **安全提示**：口令**不会**被记录。

**常见问题**

- **Q：报 `PASSPHRASE_INCORRECT`？** A：口令错误，或该文件使用了不支持的加密算法。

### PKCS#12 改密（PKCS#12 Password Changer）

- **用途**：修改 `.pfx` 的访问口令。
- **输入**：PKCS#12、原口令、新口令。
- **输出**：改密后的内容。
- **默认**：无。
- **安全提示**：请在安全环境中操作，避免原文件与结果同时留存。

**常见问题**

- **Q：改密后还能用吗？** A：可以，内容与证书链不变，只是加密口令变了。

### PKCS#7 打包（PKCS#7 Packer）

- **用途**：把证书链打包为 `.p7b`（DER 编码的 PKCS#7）。
- **输入**：证书链。
- **输出**：PKCS#7 PEM。
- **默认**：无。
- **安全提示**：PKCS#7 **不**包含私钥，**不**需要口令。

**常见问题**

- **Q：`.p7b` 能直接上传到服务器吗？** A：多数服务器需要的是 PEM 拼接，请用 [证书链解析](#证书链解析certificate-chain-parser) 导出。

### PKCS#7 提取（PKCS#7 Extractor）

- **用途**：从 `.p7b` 中取出证书。
- **输入**：PKCS#7。
- **输出**：证书 PEM 列表。
- **默认**：无。
- **安全提示**：无。

**常见问题**

- **Q：提取出来是乱码？** A：先确认文件确实是 PKCS#7 而不是 PKCS#12。

### CAA 生成（CAA Generator）

- **用途**：生成限制证书颁发机构的 DNS 记录。
- **输入**：域名、CAA 记录列表、目标 DNS 服务商。
- **输出**：对应服务商格式的记录文本。
- **默认**：TTL 3600。
- **安全提示**：CAA 只影响**公网** CA 签发，私有 CA 不受影响。

**常见问题**

- **Q：CAA 写错会怎样？** A：会导致所有公网 CA **无法**签发该域名证书 —— 修改前请确认。

### 证书链获取（Certificate Chain Fetcher）

- **用途**：从运行中的服务器抓取它实际发送的证书链。
- **输入**：主机、端口、SNI。
- **输出**：完整链与摘要。
- **默认**：端口 443，超时 15 秒。
- **安全提示**：本工具会**主动连接**目标服务器；内网地址会被安全策略拦截。

**常见问题**

- **Q：抓到的链不完整？** A：服务器配置本身可能没发全中间证书，工具只是如实呈现。

### 证书透明度查询（Certificate Transparency Search）

- **用途**：在 CT 日志中查询某个域名签发过的证书。
- **输入**：域名、匹配方式、数量上限。
- **输出**：证书摘要列表。
- **默认**：精确匹配，最多 20 条。
- **安全提示**：CT 日志是**公开**数据。

**常见问题**

- **Q：为什么查不到某些证书？** A：私有 CA 签发的证书**不**进入 CT 日志。

### 域名验证（Domain Verifier）

- **用途**：验证域名所有权（DNS TXT / CNAME / HTTP 文件）。
- **输入**：验证方式、域名、期望值、可选解析器。
- **输出**：是否匹配、逐解析器结果、HTTP 状态与响应预览。
- **默认**：超时 10 秒。
- **安全提示**：本工具会**主动访问**你的验证地址；HTTP 方式会请求 `http://<domain>/<filePath>`。

**常见问题**

- **Q：DNS 已生效但仍不匹配？** A：检查是否有多条记录、TTL 是否未过期、期望值是否多了引号。

- **输入**：操作、内容与输入编码、变体、填充选项。

- **输出**：头部、载荷、签名；生成时返回完整令牌。
- **默认**：算法 `HS256`。
- **安全提示**：**本工具不校验 RS/ES 签名真实性** —— 看到「能解出来」不代表令牌可信。

**常见问题**

- **Q：能验证 RS256 的令牌吗？** A：不能，只支持 HS 系列的结构校验。
- **Q：令牌已过期？** A：会给出 `expired` 提示，这是**结论**不是错误。

### 进制转换（Number Base Converter）

- **用途**：2–36 进制之间的数字转换。
- **输入**：值、源进制、目标进制、是否加前缀。
- **输出**：转换结果。
- **默认**：无。
- **安全提示**：无。

**常见问题**

- **Q：支持大整数吗？** A：支持，不受 64 位限制。

### 编码转换（Encoding Converter）

- **用途**：在 UTF-8、GBK、Big5、Shift_JIS、UTF-16、Latin-1 等字符编码间转换。
- **输入**：内容、源编码、目标编码、是否写 BOM。
- **输出**：转换结果（base64）。
- **默认**：源编码需指定（或 `auto` 探测）。
- **安全提示**：无法转换的字节会替换为 `�`，**可能**造成数据损失。

**常见问题**

- **Q：中文变成乱码？** A：源编码选错，先试 `GBK`。

### GZip/Deflate（GZip & Deflate）

- **用途**：压缩与解压文本或文件。
- **输入**：操作、格式（gzip / deflate / raw）、内容或文件、压缩级别。
- **输出**：结果与压缩比。
- **默认**：格式 `gzip`，级别默认。
- **安全提示**：解压有输出上限保护，防止**解压炸弹**。

**常见问题**

- **Q：解压失败？** A：确认格式选择正确（`deflate` 与 `raw` 是两种不同的 zlib 变体）。

- **Q：能查货币代码吗？** A：不能，本工具只覆盖国家 / 地区代码。

### 中国行政区划（China Administrative Regions）

- **用途**：查询省 / 市 / 县名称与代码。
- **输入**：关键词、指定省份。
- **输出**：省份与城市列表。
- **默认**：返回全部省份。
- **安全提示**：数据为**离线快照**，可能滞后于最新区划调整。

**常见问题**

- **Q：数据多久更新？** A：见响应元信息中的数据版本。

### 二维码生成（QR Code Generator）

- **用途**：生成二维码图片，或识别已有二维码。
- **输入**：操作、文本、尺寸、边距、纠错级别、前景 / 背景色、文件。
- **输出**：SVG / PNG（生成）或内容（识别）。
- **默认**：纠错级别 `M`。
- **安全提示**：二维码内容**明文**可见，**不要**放入密码或令牌。

**常见问题**

- **Q：二维码扫不出来？** A：提高纠错级别或增大尺寸；内容过长会超长。

## 系统（System）

| 工具 | slug | 一句话用途 |
| --- | --- | --- |
| cURL 命令生成 | `curl-generator` | 生成 cURL 命令 |
| Crontab 表达式生成 | `crontab-generator` | 生成 / 解释定时表达式 |
| 权限计算 | `chmod-calc` | 权限数值与符号互转 |

### cURL 命令生成（cURL Generator）

- **用途**：把请求参数转成可直接复制的 cURL 命令。
- **输入**：方法、URL、请求头、请求体、认证、选项、目标 Shell。
- **输出**：命令文本。
- **默认**：Shell `bash`。
- **安全提示**：口令与 Token 以**占位符**形式呈现，**不会**内联明文凭据。

**常见问题**

- **Q：Windows 下能用吗？** A：可以，把 Shell 切换为 `powershell` 或 `cmd`。

### Crontab 表达式生成（Crontab Generator）

- **用途**：生成定时任务表达式，并预览未来几次触发时间。
- **输入**：五个时间字段或预设名、时区。
- **输出**：表达式、未来触发时间、描述。
- **默认**：预设 `every-minute`；时区 UTC。
- **安全提示**：本工具**不**解释命令部分的安全风险。

**常见问题**

- **Q：周字段填 7 还是 0？** A：两者都表示周日，工具会统一规范。
- **Q：支持秒吗？** A：不支持，标准 crontab 为五段式。

### 权限计算（Permission Calculator）

- **用途**：在符号权限与八进制之间互转。
- **输入**：模式（符号或数值）或分类权限。
- **输出**：数值、符号、逐类权限、含义说明。
- **默认**：无。
- **安全提示**：只处理低 9 位，`setuid` / `setgid` / `sticky` **不在**范围内。

**常见问题**

- **Q：`755` 是什么意思？** A：属主可读写执行，属组与其他人可读可执行。

## 网络（Network）

| 工具 | slug | 一句话用途 |
| --- | --- | --- |
| CIDR 计算 | `cidr-calc` | 子网地址换算 |
| SSL 证书检测 | `ssl-check` | 现场握手并检查证书链 |
| DNS 查询 | `dns-lookup` | 查询各类 DNS 记录 |
| DNS 多记录测试 | `dns-tester` | whois / DNSSEC / PTR 检测 |
| WebSocket 测试 | `websocket-test` | 浏览器直连测试 |

### CIDR 计算（CIDR Calculator）

- **用途**：计算子网的网络地址、广播地址、可用主机数。
- **输入**：CIDR，或起止地址。
- **输出**：网络 / 广播 / 首末可用地址、主机数、掩码、前缀、拆分列表。
- **默认**：无。
- **安全提示**：不出网，纯计算。

**常见问题**

- **Q：`/30` 有几个可用地址？** A：2 个。
- **Q：能算 IPv6 吗？** A：可以，IPv4 与 IPv6 分别处理。

### SSL 证书检测（SSL Checker）

- **用途**：实际发起 TLS 握手，检查协商结果与证书链。
- **输入**：主机、端口、SNI、链深度、协议版本、密码套件、超时。
- **输出**：协商协议、密码套件、证书链、链是否可信、是否带 OCSP 装订。
- **默认**：端口 443，超时 30 秒。
- **安全提示**：本工具会**主动连接**目标服务器；内网地址会被拦截。

**常见问题**

- **Q：为什么看不到结果只有进度？** A：检测是流式的，进度结束才会给结论。
- **Q：支持测试旧协议吗？** A：可以指定 `versions`，但很多服务端已禁用。

### DNS 查询（DNS Lookup）

- **用途**：查询 A / AAAA / MX / TXT / NS / SRV / CAA 等记录。
- **输入**：域名、记录类型、可选服务器列表。
- **输出**：每个服务器的答案与延迟。
- **默认**：使用系统解析器。
- **安全提示**：指定服务器后**只**查询那些服务器。

**常见问题**

- **Q：怎么查国内与国外是否解析不同？** A：在 `servers` 中同时填入两组服务器对比。

### DNS 多记录测试（DNS Record Tester）

- **用途**：查询 whois 信息、检测 DNSSEC、查询 PTR 反解。
- **输入**：域名或 IP、检测项。
- **输出**：对应检测项的结果。
- **默认**：无。
- **安全提示**：whois 结果**可能不完整**（注册局限流）。

**常见问题**

- **Q：DNSSEC 显示 `supported: false`？** A：该域名未启用 DNSSEC，属正常情况。
- **Q：PTR 查 IP 还需要域名吗？** A：不需要，填 IP 即可。

### WebSocket 测试（WebSocket Tester）

- **用途**：从**浏览器**直接连接 WebSocket 服务器并收发消息。
- **输入**：地址、子协议、待发送消息。
- **输出**：是否连接成功、握手耗时、协商结果、收发内容、关闭信息。
- **默认**：无。
- **安全提示**：本工具**不经过服务器**，由你的浏览器直连目标；浏览器**无法**自定义请求头、无法使用自签证书。

**常见问题**

- **Q：为什么连不上但 curl 能连？** A：可能是跨域限制、证书不受信任或服务器要求特定子协议 / 请求头。
- **Q：服务器日志里看不到我？** A：连接由浏览器发起，来源是你的公网 IP。

### PDF 签名校验（PDF Signature Verifier）

- **用途**：校验 PDF 上的数字签名是否有效。
- **输入**：PDF 文件、可选受信任根、是否检查吊销。
- **输出**：签名列表、签名者信息、证书链结论、文件信息。
- **默认**：不检查吊销状态。
- **安全提示**：默认**不**联网检查吊销。

**常见问题**

- **Q：显示 `valid: false` 是因为 PDF 被改过吗？** A：常见原因是签名后内容被修改，或签发者证书已过期 / 不受信任。
- **Q：支持哪些签名类型？** A：常见的 PKCS#7 / CMS 签名。

### Markdown 预览（Markdown Preview）

- **用途**：渲染 Markdown，生成目录树。
- **输入**：Markdown 源文、方言、是否允许内嵌 HTML、是否把单换行当作换行。
- **输出**：HTML、目录列表。
- **默认**：方言 `gfm`，**不允许**内嵌 HTML。
- **安全提示**：输出已做净化，但前端**仍应**在隔离容器中渲染。

**常见问题**

- **Q：为什么表格没渲染？** A：请使用 GFM 方言（默认）。
- **Q：为什么 `<script>` 不生效？** A：出于安全考虑被过滤。

### EML 邮件解析（EML Parser）

- **用途**：查看邮件头、正文与附件。
- **输入**：`.eml` 文本或文件。
- **输出**：头字段、正文部分、附件列表。
- **默认**：单附件上限 10 MB。
- **安全提示**：附件内容**不**做安全扫描，请勿随意打开。

**常见问题**

- **Q：附件为什么是空的？** A：超过大小上限时只返回元信息。
- **Q：中文标题乱码？** A：邮件头编码不规范，尝试用 [编码转换](#编码转换encoding-converter) 处理。
