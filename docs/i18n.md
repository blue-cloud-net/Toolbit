# 国际化

> 状态：Draft ｜ 适用版本：v0.1.0 ｜ 最后更新：2026-10-27

Toolbit 支持 **简体中文（`zh-CN`）** 与 **English（`en-US`）** 两种界面语言。

---

## 1. 基本约定

| 项 | 值 |
| --- | --- |
| 支持语言 | `zh-CN`（默认）、`en-US` |
| 回退链 | `zh-CN` → `en-US` → 词条 key 本身 |
| 存储 | `localStorage` 键 `toolbit.locale` |
| HTML 属性 | `<html lang="zh-CN">` **必须**随语言切换更新 |
| 服务端 | **不**做内容协商；语言只影响前端 |

**必须**

- 任何用户可见文案**必须**来自 i18n 词条，**禁止**硬编码；
- 新增词条**必须**同时提供 `zh-CN` 与 `en-US`；
- 缺失翻译时**必须**回退到 `en-US`，**禁止**显示空白或 key。

---

## 2. 词条结构

```text
frontend/src/locales/
  zh-CN/
    common.json
    home.json
    tool.json
    errors.json
    tools/
      base64.json
      signature.json
      ...
  en-US/
    （同结构）
```

---

## 3. 命名空间

| 命名空间 | 内容 |
| --- | --- |
| `common.*` | 通用词（操作、复制、下载、清空、运行、示例…） |
| `home.*` | 首页（标题、副标题、搜索、分类…） |
| `tool.*` | 工具页通用（参数、结果、警告、历史…） |
| `errors.*` | 错误码文案 |
| `tools.<slug>.*` | 单个工具的名称、说明、字段标签、提示 |
| `stats.*` | 统计页 |
| `about.*` | 关于页 |
| `privacy.*` | 隐私页 |

---

## 4. 工具词条字段

每个 `tools/<slug>.json` **必须**包含下列字段（`tools.<slug>.` 为前缀省略）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 工具名称（中文） |
| `description` | string | 一句话说明 |
| `category` | string | 分类名（与 catalog 一致） |
| `actions` | object | 操作按钮（`run` / `encode` / `decode` / `verify` …） |
| `fields` | object | 输入字段标签，key = 请求字段名 |
| `options` | object | 下拉 / 分组选项文案 |
| `results` | object | 结果区标题与说明 |
| `examples` | array | 示例数据（对应工具的 `example.ts`） |
| `hints` | object | 字段级提示与安全提示 |
| `faq` | array | 常见问题 `[{ q, a }]` |

**示例**（`zh-CN/tools/base64.json`）

```json
{
  "name": "Base64 编解码",
  "description": "在文本与 Base64 之间互转。",
  "actions": {
    "encode": "编码",
    "decode": "解码"
  },
  "fields": {
    "operation": "操作",
    "input": "输入内容",
    "variant": "Base64 变体",
    "padding": "保留填充字符"
  },
  "options": {
    "variant": {
      "standard": "标准",
      "url": "URL 安全"
    }
  },
  "results": {
    "output": "输出结果"
  },
  "hints": {
    "output": "点击右上角图标可复制结果。"
  }
}
```

对应的 `en-US/tools/base64.json` **必须**字段完全一致。

---

## 5. 错误码词条

错误码文案位于 `errors.json`，key 为**大写错误码本身**（文件以 `errors` 为命名空间注册）：

```json
{
  "KEY_SIZE_MISMATCH": "密钥长度不符合要求（期望 {expected} 字节，实际 {actual} 字节）",
  "MISSING_FIELD": "缺少必填字段：{field}",
  "TOO_LARGE": "内容超出大小限制（上限 {maxBytes} 字节）"
}
```

**必须**

- 每个错误码**必须**在两种语言中都有词条；
- 占位符**必须**用 `{name}` 形式，与 `error.params` 的 key 一致；
- 缺失的占位符在运行时**必须**被安全地替换为空字符串，**禁止**显示 `{undefined}`。

---

## 6. 插值

使用 `vue-i18n` 的消息语法：

```ts
t('tools.base64.fields.operation')
t('errors.KEY_SIZE_MISMATCH', { expected: 16, actual: 24 })
```

**禁止**用字符串拼接方式做翻译（`"期望 " + n + " 字节"`），**必须**用插值。

---

## 7. 复数与量词

`vue-i18n` 使用管道语法：

```json
{
  "results": {
    "matchCount": "no match | 1 match | {count} matches"
  }
}
```

**中文**只有「其他」一项；**英文**按需提供。

---

## 8. 格式化：日期 / 数字 / 相对时间

**必须**使用 `Intl`：

```ts
new Intl.NumberFormat(locale).format(value)
new Intl.DateTimeFormat(locale, { dateStyle: 'medium' }).format(date)
new Intl.RelativeTimeFormat(locale).format(delta, 'day')
```

**禁止**手工拼接「年 / 月 / 日」等词条。

---

## 9. 日期与时区

| 场景 | 规则 |
| --- | --- |
| 工具计算 | 服务端按**显式时区**计算（`timestamp` / `date-calc` 支持 IANA 时区名） |
| 界面显示 | 按**浏览器本地时区** |
| 相对时间 | 用 `Intl.RelativeTimeFormat` |
| 绝对时间 | 用 `Intl.DateTimeFormat` |

**禁止**在界面中硬编码 `+08:00` 偏移。

---

## 10. 切换语言时的行为

**必须**

- 立即重渲染**全部**文案（含动态拼接的字段名、按钮、错误提示）；
- 切换后**保留**当前页面与表单内容；
- 更新 `<html lang>`；
- 更新 `localStorage`；
- **不**刷新页面。

---

## 11. 路由与 URL

- 工具路由**只**用 slug（`/tools/base64`），**禁止**把语言放进路径；
- 语言通过前端状态管理，**不**进入 URL 查询串。

---

## 12. 文档与文案的边界

| 内容 | 语言 |
| --- | --- |
| 界面文案 | i18n 词条 |
| 工具内说明与 FAQ | i18n 词条 |
| 文档（`docs/**`） | 中文为主，README 附英文摘要 |
| 代码标识符 | 英文 |
| 协议字段 / 错误码 | 英文 |

**禁止**在 `docs/**` 中维护一份与 i18n 重复的界面文案表。

---

## 13. 新增语言的流程

1. 复制 `frontend/src/locales/zh-CN/` 为新目录；
2. 翻译全部词条；
3. 在 `frontend/src/locales/index.ts` 注册；
4. 在 `frontend/src/i18n/` 设置默认回退链；
5. 补充语言切换器选项；
6. 更新 [tools.md](tools.md) 与 [deploy.md](deploy.md) 中的语言说明。

**必须**在加入新语言前把两种现有语言的词条**补齐**，**禁止**留下空词条。

---

## 14. 校验

CI **必须**执行词条一致性检查：

| 检查 | 失败条件 |
| --- | --- |
| key 对齐 | 两种语言 key 集合不一致 |
| 空值 | 存在空字符串或纯空白词条 |
| 占位符 | 同一 key 的占位符集合不一致 |
| 覆盖率 | catalog 中每个 `slug` 都有对应词条文件 |

校验由 `scripts/check-docs.mjs` 负责。

---

## 15. 禁止清单

- ❌ 在组件中硬编码用户可见文案。
- ❌ 只提供一种语言的词条。
- ❌ 用字符串拼接做翻译。
- ❌ 在错误文案中拼接用户输入。
- ❌ 把语言写进 URL 路径。
- ❌ 手工拼接「年 / 月 / 日」等日期单位。
